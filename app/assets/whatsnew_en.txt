Snapdragon 8 Elite diagnostic Dev: logs the first DiT block input and output for MOSS and Mage to pinpoint where non-finite values begin. This build diagnoses the failure; it does not claim to fix it.

# New in 1.9.6-v79-sd8e-diag
Snapdragon 8 Elite diagnostic Dev: MOSS logs DiT latent and VAE RGB statistics to help locate image corruption. Still experimental; export logs immediately if the image looks wrong.

# New in 1.9.6-v79-sd8e-dev
Experimental Snapdragon 8 Elite (SM8750) test: V79 MOSS and Mage routes, the MOSS V79 VAE and V79 Real-ESRGAN. Anima and Qwen are blocked because their V79 contexts are not included yet. Not tested on an SD8E phone; export logs immediately if anything fails.

# New in 1.9.6-v73.3-8sG4-test
Experimental Snapdragon 8s Gen 4 (SM8735) test route reusing V73 kernels. FP16 and QNN context compatibility are unverified; report model-by-model results and export logs after failures.

# New in 1.9.6-v73.2
Qwen photo edits: corrected a portrait output size rejected by the NPU runner, fixed Android shell syntax, and stopped the VAE from starting when a generation cannot proceed.
Settings can check GitHub Releases, verify the APK's SHA-256 and install an update while keeping app data.
Share now uses the correct gallery provider in Dev builds. MOSS tries the existing V73 route on Snapdragon 8 Gen 3 (experimental).
# Included in 1.9.6
Import and export Anima model packs in folders: validates the manifest, sizes and SHA-256 before restore; rolls back new files if an import fails or is cancelled.
Offline model catalog: browse saved models without internet; downloads stay disabled until the connection returns.
Optional automatic saving: copies each finished picture to the Gallery or an Android folder you choose, while keeping the History copy.
Corrections and upscaling preserve generation metadata in the PNG and add the correction/upscale step.
Stopping a generation or deleting a model asks for confirmation. If Anima fails to finish loading, the app shows the chip and the latest log lines.
Adjust the remaining image count while a batch runs without changing the image already in progress.
Choosing the default negative prompt fills it in and enables CFG 4 when CFG 1 would otherwise skip it.

# From 1.9.5
ADetailer after the picture: the picture shows first, then the face and/or hands are detailed (new "ADetailer (hands)" in Extras). With turbo models the fingers can still come out odd.
Full metadata in the pictures: prompt, negative, steps, sampler, CFG, seed, model, LoRA hashes and the Civitai resources, so Civitai recognises them on upload.
History: a "Copy prompt" button (or tap the prompt). Configuration templates: long-press one to overwrite it with the current settings.
# From 1.9.4
Mage without a size limit: the model runs in windows on the NPU, pictures up to 2048×3072 (1536×1536 in ~72 s) and reference photos at full size.
Anima without a size limit: up to 4096×4096 (1536×1536 in ~50 s), with big sizes in the list.
"How much it changes" (Edit a photo): tap the number to type the percentage. The step counter with a photo counts the real steps.
# From 1.9.3
Outfit swaps that keep the quality (Qwen and Mage): add the photo and the picture with the clothes, paint the clothes with "✎ Area to edit" and generate; only the painted area changes, the body, hands and pose stay. "👗 Copy its outfit" and "🧍 Copy its pose" read image 2 and write the prompt. With a reference picture Qwen always uses "High fidelity": the garment is copied much closer (name its colour and pattern in the prompt).
Anima's "Edit a photo" and "Pose" fold away to take less room.
Prompt from a picture: "Character only" keeps nudity and body traits. LoRAs: the button opens each model's library and the strength goes up to 5.
# From 1.9.2
Configuration templates (⋯ menu): save the model, prompt, negative, steps, CFG, size, LoRAs and extras under a name (e.g. "3D Style") and load it all back with one tap.
Pose for Anima (experimental): in "Edit a photo" → POSE, pick a picture or the last one and new pictures copy its posture. It uses Claquasse's adapter (non-commercial); made for Anima Base 1.0, few-step turbo models follow it less.
# From 1.9.1

Prompt from a picture: "Character only" keeps hair, eyes, clothes and accessories, without pose or background, to write a new pose or style (Anima and MOSS).
Negative prompt templates: save, pick and reuse recent ones.
Settings: a GitHub row with the version.
